# 需求与实施规格说明书：Chrome 高阶标签页切换器 (Power Tab Switcher)

## 1. 项目概述
基于 Chrome Manifest V3，将轻量的“Alt + 滚轮标签切换”扩展升级为全功能的**高阶标签页切换与速览管理器**。保持单刻度防抖与现代毛玻璃 UI，加入 MRU 排序、弹窗内管理、无键盘手势与系统级兜底。

---

## 2. 核心增量功能清单 (Feature Specs)

### 模块 A：排序模式扩展（MRU vs 物理顺序）
1. **MRU（Most Recently Used）最近使用顺序**：
   - **机制**：在 `background.js` 中维护一个全局激活栈 `mruStack: number[]`（记录 `tabId`）。
   - 监听 `chrome.tabs.onActivated` 与 `chrome.tabs.onRemoved` 动态维护栈顶。
   - 打开弹窗时若处于 MRU 模式，标签列表按“当前页 -> 上一次访问的页 -> 上上次...”排列，实现两网页间单格极速横跳。
2. **标签栏物理顺序（Index）**：
   - 保持现有逻辑，按视觉从左到右（水平）或从上到下（垂直）排序。
3. **设置项切换**：在 Options 页面提供 `sortMode: 'mru' | 'index'` 单选切换。

---

### 模块 B：HUD 弹窗交互增强（管理与跳转）
1. **鼠标中键（Middle Click）/ 按键 W/Delete 关闭标签**：
   - 浮窗呼出时，滚轮中键点击某一行，或键盘按下 `Delete` / `Backspace` / `w` 键，立即调用 `chrome.tabs.remove(tabId)`。
   - 浮窗列表实时收缩动画，`tabsData` 动态移除该项并修正 `currentIndex`。
2. **鼠标左键单击直接跳转**：
   - 允许鼠标在弹窗卡片上移动，鼠标指针移动到某行时激活悬停样式。
   - 左键单击任意标签卡片，立即调用 `ACTIVATE_TAB` 跳转并关闭弹窗。
3. **纯键盘辅助导航**：
   - 弹窗展示中，允许按键盘 `ArrowUp` / `ArrowDown` 或 `Tab` / `Shift+Tab` 移动高亮选择项。

---

### 模块 C：单手手势支持（Rocker Gesture: 右键 + 滚轮）
1. **纯鼠标盲操**：
   - 允许在 Options 中开启 `rockerGesture: boolean`（按住右键 + 滚轮）。
2. **触发与拦截机制**：
   - 监听 `mousedown (button === 2)` 标记 `isRightMouseDown = true`。
   - 在右键按住期间检测到 `wheel` 事件，判定为手势触发：
     - 设置 `isRockerActive = true`；
     - 呼出 HUD 弹窗并移动高亮；
     - 严格拦截随后的 `contextmenu` 默认右键菜单。
   - 监听 `mouseup (button === 2)`：若 `isRockerActive === true`，确认跳转至目标标签，重置状态。若期间单击左键则视为取消。

---

### 模块 D：多维度视觉与状态标识 (Visual & Status)
1. **音频播放与静音状态**：
   - `background.js` 传递 `audible: boolean` 和 `muted: boolean`。
   - 在发声标签旁渲染动态音量小喇叭 🔊（CSS 浅绿色脉冲呼吸动画）；静音时渲染 🔇。
   - 在弹窗中按下键盘 `M` 键，可直接发送 `TOGGLE_MUTE` 切换当前高亮标签的静音状态。
2. **固定标签 (Pinned) 与标签分组 (Tab Groups)**：
   - 固定标签展示图钉标识 📌。
   - 检查 `tab.groupId !== -1`：
     - 调用 `chrome.tabGroups.get(groupId)` 获取分组 `title` 与 `color`。
     - 在标签行内渲染带原生配色的微型徽章（例如：`[工作]` 蓝色、`[参考]` 绿色）。
3. **休眠状态标识 (Discarded)**：
   - 若 `tab.discarded === true`（内存节省程序冻结的标签），渲染微灰小雪花或休眠图标 💤，给予激活需重载的预期。

---

### 模块 E：极端边界防御与快捷键兜底
1. **全局快捷键兜底 (Chrome Commands)**：
   - 在 `manifest.json` 中注册 `_execute_action` 或自定义 command：
     - `alt_tab_next` (例如绑定 `Alt+Q`)。
     - `alt_tab_prev` (例如绑定 `Alt+W`)。
   - 即使当前停留在 `chrome://settings/` 等安全受限页面，直接由 `background.js` 捕获快捷键进行盲切，彻底消除死角。
2. **多显示器/多窗口隔离**：
   - 每一个查询和切换指令均显式附带 `sender.tab.windowId`，严禁影响其他屏幕/非当前窗口。

## 3. 进程间通信协议契约 (IPC Message Contracts)

### 前台发送 -> 后台处理 (`content.js` -> `background.js`)

| 消息类型 (`type`) | 附带载荷 (`payload`) | 预期返回 (`response`) | 说明 |
| :--- | :--- | :--- | :--- |
| `GET_TABS` | `{ sortMode: 'mru' \| 'index' }` | `{ tabs: EnhancedTab[] }` | 获取当前窗口增强标签列表 |
| `ACTIVATE_TAB` | `{ tabId: number }` | `{ status: 'ok' }` | 激活并跳转到目标标签 |
| `CLOSE_TAB` | `{ tabId: number }` | `{ status: 'ok', remainingCount: number }` | 弹窗中关闭标签页 |
| `TOGGLE_MUTE` | `{ tabId: number }` | `{ status: 'ok', muted: boolean }` | 切换指定标签静音状态 |

#### `EnhancedTab` 结构定义
```typescript
interface EnhancedTab {
  id: number;
  title: string;
  favIconUrl: string;
  active: boolean;
  index: number;
  pinned: boolean;
  audible: boolean;
  muted: boolean;
  discarded: boolean;
  group?: {
    id: number;
    title: string;
    color: string; // 'grey' | 'blue' | 'red' | 'yellow' | 'green' | 'pink' | 'purple' | 'cyan' | 'orange'
  };
}
```

## 4. 核心逻辑实现参考 (Agent 编码指引)

### 4.1 Background MRU 栈维护算法
```javascript
// background.js 内部状态
const windowMruMap = new Map(); // windowId -> tabId[]

chrome.tabs.onActivated.addListener(async (activeInfo) => {
  const { windowId, tabId } = activeInfo;
  let stack = windowMruMap.get(windowId) || [];
  stack = stack.filter(id => id !== tabId);
  stack.unshift(tabId); // 最新激活的压入栈顶
  windowMruMap.set(windowId, stack);
});

chrome.tabs.onRemoved.addListener((tabId, removeInfo) => {
  const { windowId } = removeInfo;
  let stack = windowMruMap.get(windowId);
  if (stack) {
    windowMruMap.set(windowId, stack.filter(id => id !== tabId));
  }
});
```

### 4.2 Content Script 安全通信与中键关闭
```javascript
// 中键点击关闭标签
cardListEl.addEventListener('auxclick', (e) => {
  if (e.button === 1) { // 1 = 鼠标中键
    e.preventDefault();
    e.stopPropagation();
    const row = e.target.closest('.tab-row');
    if (!row) return;
    const targetIdx = parseInt(row.dataset.index, 10);
    const targetTab = tabsData[targetIdx];
    if (!targetTab) return;

    safeSendMessage({ type: 'CLOSE_TAB', tabId: targetTab.id }, (res) => {
      tabsData.splice(targetIdx, 1);
      if (currentIndex >= tabsData.length) currentIndex = tabsData.length - 1;
      renderHud();
    });
  }
});
```

## 5. 验收标准与测试用例 (QA Acceptance)

1. **MRU 准确性测试**：
   - 打开 5 个标签页依次点击 1、3、5，按住 Alt 滚一格，高亮目标必须是上一次访问的 3，再次松开能瞬间切回。
2. **无键盘单手手势测试**：
   - 开启摇杆手势，鼠标在网页任意处**按住右键同时滚轮**，正常唤出切换弹窗；松开右键正常跳转；松开后**严禁弹出**浏览器的默认右键上下文菜单。
3. **媒体与分组 UI 渲染**：
   - 播放任意网页视频时，弹窗对应条目必须显示小喇叭；对有 Tab Group 的标签必须准确展示分组颜色胶囊。
4. **弹性容错测试**：
   - 在控制台重载扩展程序（触发 `context invalidated`），在未刷新的网页上疯狂滚动滚轮并按右键，页面控制台严禁出现未捕获的红字异常。
