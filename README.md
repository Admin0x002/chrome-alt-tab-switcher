# Power Tab Switcher (Chrome 高阶标签页切换器)

基于 Chrome Manifest V3 构建的高阶标签页切换与速览管理器。告别传统标签栏繁琐查找，提供类似系统级 Alt+Tab 的毛玻璃居中浮窗、MRU（最近使用）极速横跳、鼠标防误触跟随、快捷键与中键即时关闭以及音频/分组多维状态指示。

---

## ✨ 核心特性

- 🪟 **现代毛玻璃 HUD 弹窗**：居中浮窗速览标签页标题、图标、分组与运行状态，单刻度精准防抖。
- ⚡ **MRU 最近使用排序**：在后台维护各窗口的标签页激活栈，默认优先排布最近访问的网页，实现两个或多个工作页面间的极速往返。
- ⌨️ **多维触发方式**：
  - `Alt + 鼠标滚轮`：快速滚动浏览。
  - `Alt + ↑ / ↓ 方向键`：纯键盘盲切，支持松开 `Alt` 瞬间跳转。
- 🖱️ **人性化鼠标交互与防误触**：
  - **防误触阈值保护**：浮窗呼出时光标位置自动锁定，支持自定义移动像素阈值（默认 10px），防止原本停在屏幕中央的光标抢夺焦点。
  - **左键单击即刻跳转**：鼠标点击任意卡片瞬间激活。
  - **中键滚轮关闭**：鼠标中键点击卡片直接关闭该标签页。
- 🎯 **键盘辅助管理**：
  - `W` / `Delete` / `Backspace` / `Esc`：快速关闭当前高亮的标签页。
  - `M` 键：快速切换当前高亮标签的静音状态。
  - `↑` / `↓` / `Tab` / `Shift+Tab`：移动高亮选中项。
  - `Enter`：确认激活。
  - `鼠标右键`：随时取消切换并关闭浮窗。
- 🎨 **丰富状态标识**：
  - 🔊 **音频播放与静音**：正在发声的标签页带有绿色呼吸脉冲音量图标，静音标签页带有 🔇 标识。
  - 📌 **固定标签**：图钉标识。
  - 💤 **休眠状态**：内存冻结标签页标记雪花/休眠 💤。
  - 🏷️ **Tab Groups 分组**：完美提取 Chrome 原生分组标题与专属配色徽章。
- ⚙️ **高度可定制的偏好设置**：
  - 排序模式切换（MRU 最近使用 vs 标签栏物理顺序）。
  - 滚轮模式（严格物理刻度段落模式 / 触控板平滑累加模式）。
  - 灵敏度阈值、滚动方向反转、首尾循环切换。
  - 鼠标悬停高亮开关与移动像素阈值调节（0~60px）。
  - Alt + 方向键唤出开关。

## 🚀 安装与使用

### 开发者模式手动加载

1. 克隆或下载本项目至本地：
   ```bash
   git clone https://github.com/Admin0x002/chrome-alt-tab-switcher.git
   ```
2. 打开 Chrome 浏览器，在地址栏输入：
   ```text
   chrome://extensions/
   ```
3. 在右上角开启 **“开发者模式”**（Developer mode）。
4. 点击左上角的 **“加载已解压的扩展程序”**（Load unpacked），选择本项目所在的文件夹根目录。
5. 安装完成，打开任意网页即可直接体验！

## ⌨️ 快捷操作一览

| 触发场景 | 操作方式 | 效果说明 |
| :--- | :--- | :--- |
| **呼出与浏览** | `Alt + 鼠标滚轮` 或 `Alt + ↑ / ↓` | 唤出 HUD 浮窗并顺次移动高亮 |
| **确认切换** | 松开 `Alt` 键 / 按 `Enter` / 鼠标左键单击 | 激活选中的标签页并关闭浮窗 |
| **关闭标签** | 按 `Esc` / `W` / `Delete` / `Backspace` / 鼠标中键单击 | 关闭当前高亮（或点击）的标签页 |
| **切换静音** | 按 `M` 键 / 单击喇叭图标 | 快速切换该标签页的播放静音状态 |
| **取消切换** | 点击鼠标右键 | 取消本次操作并立即关闭浮窗 |

## 🛠️ 项目结构

```text
.
├── background.js     # 后台 Service Worker（维护 MRU 栈、标签聚合与分组、消息调度）
├── content.js        # 前台 Content Script（Shadow DOM HUD 渲染、键鼠交互、手势防误触）
├── manifest.json     # Chrome Extension MV3 配置文件
├── options.html      # 设置页 HTML 界面
├── options.js        # 设置页数据同步逻辑
└── docs/prd/         # PRD 需求文档
```
